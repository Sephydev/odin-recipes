# Odin Recipe

## Description

This project come from [The Odin Project](https://www.theodinproject.com/lessons/foundations-recipes). It consist of creating a simple recipe website with multiple recipes in order to use what we've learned during the HTML section of the Foundation module.

See the [Live Demo](https://sephydev.github.io/odin-recipes/)

## What I used

During this project, I mainly used basic HTML tags, for example `<h1></h1>`, `<img>` or `<ul><li></li></ul>`. I used images, unordered list and ordered list, paragraph and headings in order to complete this project. I also used `<figure>` and `<figcaption>`, tags we didn't learned at this stage in The Odin Project, to add credits to the images I used.
